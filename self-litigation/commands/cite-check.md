description: 판례 사건번호·법조문 검증 — 없으면 기각, 있으나 내용이 다르면 경고
---
`cite-check` 스킬을 읽는다. 인자 `$ARGUMENTS` 로 사건번호/조문 목록을 받고, 없으면 `case/` 파일 전체에서 사건번호 패턴을 추출한다.

1. `python3 scripts/cite_check.py <사건번호...>` 를 실행해 형식 검사와 (환경변수 `NAHOLO_LAW_OC` 가 있으면) law.go.kr 존재 확인을 한다.
2. 존재하는 판례는 요지를 가져와(WebFetch 가능 시) 우리가 인용하려는 명제와 대조한다.
3. 결과 표(확인됨/기각/경고)를 보여주고, 기각·경고된 인용은 `case/` 문서에서 제거 또는 수정한다.
4. 사용자에게 검증 근거 URL을 남겨 직접 확인하게 한다.
