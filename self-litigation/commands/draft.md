---
description: 소장·지급명령신청서·답변서·준비서면 초안 작성 (case/40_drafts/)
---
`writing-rules`, `procedure`, `elements`, `case-file` 스킬과 `case/` 파일 전부를 읽는다. `templates/` 의 서식 뼈대를 사용한다.

인자: `$ARGUMENTS` 에 문서 종류(소장 / 지급명령 / 답변서 / 준비서면)를 받는다. 없으면 묻는다.

1. 요건사실 표에 ❌가 있으면 초안 전에 경고하고 그래도 진행할지 묻는다.
2. 구성(소장): 원고·피고 표시 → 사건명(예: 대여금) → 청구취지(금액, 이자, 소송비용, 가집행) → 청구원인(요건사실 순서대로, 각 문장 끝에 근거 증거 `(갑 제N호증)`) → 입증방법 → 첨부서류 → 날짜·법원명.
3. 청구원인은 사실만, 시간순으로, 짧은 문장으로. 감정 표현·상대 비난 문구는 넣지 않는다.
4. 판례·조문은 검증된 것만. 검증 안 된 것은 넣지 않는다.
5. 파일 상단에 "AI 보조 초안 · 법률자문 아님 · 제출 전 본인 확인" 고지를 넣는다.
6. `case/40_drafts/<문서>_v<N>.md` 에 저장하고, 사용자에게 **직접 읽고 사실과 다른 부분을 표시**해 달라고 요청한다. 초안을 사용자 대신 확정하지 않는다.
7. 정부 서식 원본 링크(나홀로소송 서식 페이지)를 같이 준다.
