# 요건사실 카탈로그 (소액사건 빈출 유형)

> 요건사실 = 청구가 인정되려면 원고가 주장·증명해야 하는 사실. 각 요건마다 "어떤 증거로 보이는가"를 함께 적는다.
> 항변 = 피고가 들고 나올 수 있는 반박. 사용자에게 반드시 미리 보여준다(아부 방지).
> 본 카탈로그는 출발점이다. 사건에 맞지 않으면 사용자에게 사실을 더 묻고, 확실하지 않은 법리는 `[확인]`으로 표시한다.

## 1. 대여금 (돈을 빌려줬다)
| 요건사실 | 전형적 증거 |
|---|---|
| 금전소비대차 약정(빌려주기로 한 합의) | 차용증, 카톡/문자("빌려줘", "갚을게"), 통화녹음 |
| 금전 교부(실제로 돈을 줌) | 계좌이체 내역, 현금 영수 확인 문자 |
| 변제기 도래(갚기로 한 날이 지남) 또는 기한 없으면 상당기간 정한 최고 | 차용증의 변제기, 독촉 문자·내용증명 |
- 예상 항변: 증여(그냥 준 돈)였다 / 이미 갚았다(변제) / 다른 채권과 상계 / 소멸시효(10년, 상사 5년).
- 이자: 약정 이자 없으면 민사 연 5%, 소장 송달 다음날부터 소송촉진법 연 12% `[확인]`.

## 2. 물품대금·용역대금 (물건을 팔았다/일을 해줬다)
| 요건사실 | 증거 |
|---|---|
| 매매(또는 도급) 계약 체결 | 견적서, 발주서, 계약서, 주문 메시지 |
| 물건 인도 / 일 완성 | 거래명세서, 인수증, 납품 사진, 완료 확인 메시지 |
| 대금액과 지급기일 | 세금계산서, 청구서 |
- 항변: 하자(물건 문제) / 미완성 / 대금 일부 지급 / 상사 소멸시효 5년, 상인의 물품대금은 3년 `[확인]`.

## 3. 임대차보증금 반환
| 요건사실 | 증거 |
|---|---|
| 임대차계약 체결과 보증금 지급 | 계약서, 이체내역 |
| 임대차 종료(기간 만료·해지 통지) | 해지 통보 문자, 계약서 기간 |
| 목적물 인도(집을 비워 줌) 또는 동시이행 제공 | 이사 사진, 열쇠 반납 문자, 전출 기록 |
- 항변: 원상회복비·연체차임·관리비 공제 / 묵시적 갱신 / 아직 인도 안 됨(동시이행).
- 주의: 임차권등기명령·주택임대차보호법 특례는 별도 절차. 소액 범위(3천만원) 초과가 흔하므로 소가 확인.

## 4. 손해배상 (불법행위: 교통사고 소액, 층간소음, 명예훼손, 반려동물 등)
| 요건사실 | 증거 |
|---|---|
| 가해행위(고의·과실) | 사고 사실확인원, CCTV, 녹음, 게시글 캡처 |
| 위법성 | (원칙적으로 추정, 정당행위 항변은 피고 몫) |
| 손해 발생과 금액 | 진단서, 수리 견적서·영수증, 위자료 산정 근거 |
| 인과관계 | 시간·장소·경위의 일관성, 감정 |
- 항변: 과실상계(원고도 잘못) / 손해액 과다 / 시효(안 날부터 3년, 행위일부터 10년).
- 위자료는 법원 재량. 금액 근거 없이 크게 쓰면 인지만 낭비 — 사용자에게 분명히 말한다.

## 5. 임금·퇴직금
- 노동청 진정(무료, 빠름)이 먼저인 경우가 많다. 체불임금 확인서가 있으면 소송이 쉬워지고 법률구조공단 무료 구조 대상.
| 요건사실 | 증거 |
|---|---|
| 근로계약 관계 | 근로계약서, 급여명세, 출퇴근 기록, 카톡 지시 |
| 근로 제공 | 근무 기록 |
| 임금 미지급과 금액 | 급여 이체내역, 체불임금 확인서 |
- 시효 3년. 지연이자: 퇴직 후 14일 경과 시 연 20% `[확인]`.

## 6. 부당이득 반환 (잘못 보낸 돈, 중고거래 사기 환불 등)
| 요건사실 | 증거 |
|---|---|
| 피고의 이득 | 이체내역 |
| 원고의 손실 | 동일 |
| 법률상 원인 없음 | 착오 송금 경위, 물건 미수령 증거, 경찰 사건 기록 |
- 사기 피해는 형사고소와 병행 가능. 형사 판결문·수사기록은 강력한 증거.
