## 1. 키워드 맵

### 1-1. 방법론 (직접 실행용)
숫자 확보가 필요하면 아래 순서로 30분 내 채울 수 있음.
1. 네이버 검색광고 키워드도구(searchad.naver.com → 도구 → 키워드 도구): 월간 PC/모바일 검색수·경쟁정도. 무료 래퍼: [마케팅마법사](https://placewizard.kr/keymany.php), [SURF](https://surffing.net/), [AI마스터](https://ai-keyword-master.com/keyword-volume) (블로그 문서수까지 표시 → 경쟁도 산출).
2. 네이버 데이터랩 검색어 트렌드(최대 5개 비교, 성별·연령·기기별 상대치): [활용 가이드](https://www.ascentkorea.com/naver-datalab-guide/). 추천 비교 세트: `나홀로소송, 소액소송, 지급명령, 셀프소송, 내용증명`.
3. 구글 트렌드(한국, 지난 12개월) + 구글 자동완성/PAA("People also ask") + 유튜브 검색창 자동완성.
4. 경쟁도는 "상위 10개 중 정부·법원(easylaw, ecfs.scourt, klac) 비중"으로 판단. 정부 페이지가 3개 이상이면 정보형 키워드는 정부 자료 리라이트+경험담으로만 뚫림.

### 2-2. 2026년 네이버 알고리즘 변화가 이 프로젝트에 유리한 점
- 블로그·카페·웹사이트 경계가 사라지고 "출처 신뢰도(AuthGR)"로 동일 평가 → 변호사 실명 자체 도메인이 네이버에서도 동등 출발선 ([로카포스팅 체크리스트](https://locaposting.com/blog/naver-seo-checklist), [로이어픽 "네이버 2026 3가지 변화"](https://lawyer-pick.com/insights/naver-2026-3-changes)).
- AI 브리핑은 "원인·이유형 정보 키워드"에서 안정 노출, "추천·비교" 상업 키워드는 제한 ([seonews](https://seonews.co.kr/naver-ai-briefing-exposure-rules/), [원플랜 4가지 조건](https://blog.oneplan.co.kr/naver-ai-search-optimization/)) → "이행권고결정이 뭔가요/왜 오나요" 식 제목이 유리.

- 변호사들이 "AI가 추천해서 왔다"는 의뢰인을 이미 경험 중 ([법률신문 2026](https://www.lawtimes.co.kr/news/articleViewAmp.html?idxno=223827)) → 생성형 AI 인용(GEO)까지 겨냥.
- 네이버 인플루언서 카테고리에 '법률' 없음(경제/비즈니스·어학/교육 등만) ([나무위키](https://namu.wiki/w/%EB%84%A4%EC%9D%B4%EB%B2%84%20%EC%9D%B8%ED%94%8C%EB%A3%A8%EC%96%B8%EC%84%9C)) → 인플루언서 탭 전략은 기각.
- 네이버 블로그는 구글 크롤링이 제한적이어서 구글 유입이 거의 없음 ([AWEZARD](https://awz.kr/blog-platform-comparison-seo/)).

### 2-3. 결론: 이 타깃에 맞는 채널 배분
- **허브 = 자체 도메인(워드프레스 또는 티스토리 + 독립 도메인)**. 구글·네이버(웹문서/AI 브리핑)·ChatGPT/Gemini 인용을 동시에 노림. 변호사 실명·소속·광고책임변호사 표기를 푸터에 고정(7장 참조).
- **네이버 블로그 = 위성**. 허브 글을 800~1,500자로 요약 + 캡처 1~2장 + 허브 링크. 주 1회. 네이버 지식인은 상위 노출이 '따봉' 기반이라 시간 대비 효율 낮음 → 보류 ([지식인 가이드](https://j-stagram.com/blog/naver-kin-guide)).
- **유튜브 쇼츠** = 발견 채널(중고거래 사기·층간소음 같은 감정형 사건에 강함). 단, 쇼츠는 AI 검색이 텍스트로 색인하기 어려워 검색 자산이 아니라 유입 자산 ([로이어애드 숏폼 vs 롱폼](https://blog.lawyerad.kr/lawyer-youtube-content-strategy)).
- **스레드** = 얼리어답터·AI 사용자 커뮤니티, 키트의 1차 구매층. 국내 MAU 543~630만(2025-08, 1년 새 +180%), 2026년 X 추월 700만+ 추정 ([bien.ltd](https://bien.ltd/blogs/threads-korea-user-growth-x-competition/), [스레드 통계 게시물](https://www.threads.com/@yolona_kr/post/DPx7bfXEs7P/)). 스레드 활동 변호사 계정은 팔로워 2만~3.6만 규모 ([로웨이브 "스레드 변호사"](https://www.lawwave.kr/feel/970)).

### 3-3. 빈틈 (공략 포인트)
1. **AI 활용 실행 가이드 부재**: 뉴스는 넘치는데 "무슨 모델을, 어떤 순서로, 무엇을 넣고, 무엇을 검증하라"는 실무 글이 검색 상위에 없음. 특히 "역할부여 프롬프트 하지 마라" 같은 반(反)통념 팁은 스레드에서만 유통.
2. **가짜 판례 검증 루틴**: 법조신문·뉴시스가 문제만 제기. "판례 검증 체크리스트(종합법률정보·케이스노트 대조)" 콘텐츠가 없음.
3. **최신 기준 반영 불일치**: 상위 콘텐츠 중 KDI 나라경제(2015) 등 "2천만원 이하" 잔존 ([KDI](https://eiec.kdi.re.kr/publish/naraView.do?fcode=00002000040000100019&cidx=9745&sel_year=2015&sel_month=01)). 송달료 단가도 5,500원/6,000원이 혼재 ([itislaw 2026](https://itislaw.co.kr/e-litigation-cost/) vs [easylaw]) → "2026년 9월 기준" 표기 + 출처 링크만으로 차별화.
4. **피고(답변서·이행권고결정 받은 사람) 콘텐츠 희소**: 원고 대상 글이 90%.
5. **중고거래 사기 민사**: 커뮤니티 후기뿐, 변호사가 정리한 "형사 배상명령 vs 소액 민사 vs 지급명령" 의사결정 트리 없음.
6. **화면 캡처 기반 전자소송 워크스루**: 개인 블로그 1~2개가 독식. 변호사 실명 + 2026 UI로 갱신하면 교체 가능.
7. **소액사건 판결이유 기재 노력의무(2023-03-28 개정 소액사건심판법)** 같은 최신 제도 설명 콘텐츠 부재 ([법령센터](https://www.law.go.kr/LSW/lsInfoP.do?lsId=001219)).

## 4. 콘텐츠 캘린더 (원소스 멀티유즈)

### 4-1. 변환 규칙: 블로그 롱폼 1편 → 쇼츠 3개 → 스레드 5개
**롱폼(허브) 규격**: 3,000~5,000자, H2 6~8개, 상단에 "3줄 요약 + 2026-09 기준 + 출처(법원/법제처 링크)", 중간에 실제 전자소송 화면 캡처 3장 이상, 하단에 리드마그넷 CTA 1회 + 키트 CTA 1회. 제목 공식: `[사건유형] + [절차 키워드] + [AI/숫자/연도]`.

**쇼츠 3개 (각 45~60초, 9:16, 자막 필수)**
1. 훅형 "이거 모르면 돈 못 받습니다": 롱폼의 가장 큰 실수 1개(예: 피고 주소 틀리면 각하).
2. 화면 워크스루형: 전자소송 화면 녹화 3단계를 30초로 압축 + "전체는 블로그".
3. AI 시연형: 프롬프트 입력 → 초안 → 변호사가 빨간펜으로 고치는 장면(신뢰 + 키트 티저).
공통: 첫 1.5초에 결론 자막, 마지막 3초에 "링크는 프로필".

**스레드 5개 (텍스트 300자 내, 이미지 0~1장)**
1. 반통념 한 줄("역할부여 프롬프트 쓰지 마세요") + 이유 2줄.
2. 숫자 카드(인지대 25,000원/송달료 10회분 등 롱폼의 숫자 1개).
3. 실패담·현장 관찰(익명화된 사례).
4. 질문형("지급명령 받으셨나요? 2주 지나면 끝입니다. 뭘 해야 할까요") → 댓글 유도.
5. 체크리스트 5줄 + 블로그 링크(스레드는 링크 노출이 도달을 줄이므로 5개 중 1개에만).
게시 순서: 스레드 1·3 → 쇼츠 1 → 블로그 공개 → 스레드 2·4 → 쇼츠 2·3 → 스레드 5.

6. FAQ: 변호사 자문 아님·결과 보장 없음·환불 정책.
7. 무료 리드마그넷 2차 CTA(이메일 수집).

## 6. 스레드 톤 분석 + 시리즈 10개

### 6-1. 원글 톤 분석 (첨부 이미지의 인용문 기준, 82 likes)
"나홀로 소송 AI 도움받아 하시는 분들 — 고급모델 쓰시고, 역할부여 프롬프트 쓰지 마시고…"
- **반통념(contrarian)**: 스레드/유튜브에 널린 "역할부여가 정설" 류 조언([예: 역할부여 추천 게시물](https://www.threads.com/@specal1849/post/DJUsdkYhPn4/))과 정면 충돌 → 논쟁성·저장 유도.
- **실무자 1인칭 + 명령형 짧은 문장**: "~하시고, ~하지 마시고" 나열. 근거 설명은 뒤에 짧게.
- **청중을 특정**: "AI 도움받아 하시는 분들" — 이미 하고 있는 사람에게 말함(초심자 계몽 X). 스레드 변호사들이 개인 목소리·민낯형 글로 반응을 얻는다는 관찰과 일치 ([로웨이브](https://www.lawwave.kr/feel/970)).
- **팔지 않음**: 링크·상품 없음. 신뢰 자산을 먼저 쌓는 구조.
- 참고로 같은 계정의 다른 글(Claude for legal·플러그인 분석)도 "법률가 중 AI를 가장 잘 쓰는 축" 이라는 자기 포지션을 반복 ([게시물](https://www.threads.com/@hongso0921/post/DYn75Fdk1ZJ/)) → 시리즈의 일관된 페르소나.

### 6-2. 이어갈 스레드 시리즈 10개 초안 (각 300자 내)
1. **"역할부여 대신 이걸 주세요"** — 사실관계 타임라인, 증거 목록, 상대 주장 요약. AI는 배역이 아니라 재료가 필요합니다. (원글 후속)
2. **"고급모델을 쓰라는 이유"** — 소장은 문장력 문제가 아니라 요건사실 누락 문제. 저가 모델이 빠뜨리는 것 1개 예시.
3. **"AI가 준 판례, 이렇게 확인하세요"** — 사건번호로 종합법률정보/케이스노트 검색, 없으면 버림. 지난달 본 가짜 판례 유형 2가지.
4. **"지급명령 받고 2주 방치한 분"** — 확정되면 판결과 같은 효력. 이의신청은 AI로 30분이면 씁니다.
5. **"3천만원 넘으면 소액사건이 아닙니다"** — 아직 2천만원으로 아는 글이 많음. 기준 바뀐 지 9년.
6. **"소액소송 진짜 비용"** — 500만원 청구: 인지 2.5만, 송달료 10회분, 전자소송 10% 할인. 변호사비 빼면 이게 전부.
7. **"AI로 쓴 40쪽 서면, 판사는 읽지 않습니다"** — 길이가 아니라 구조. 법조신문 기사 언급 + 5쪽으로 줄이는 프롬프트 방향.
8. **"중고거래 사기 30만원, 소송할 가치 있나"** — 배상명령신청 먼저, 안 되면 지급명령. 시간 대비 계산.
9. **"피고가 된 분들께"** — 소장 받으면 30일 답변서. 원고용 글은 많고 피고용 글은 없어서 씁니다.
10. **"그래서 키트를 만들었습니다"** — 9개 글의 프롬프트·체크리스트를 묶었다는 담백한 공지. 가격·링크는 댓글에. (시리즈 마지막에만 판매)

운영 규칙: 링크는 10개 중 1~2개에만, 나머지는 텍스트 완결. 각 글에 "댓글로 사례 주시면 다음 글에" 로 UGC 유도. 변호사 사칭 계정 이슈([네이트 2026-07-31](https://m.news.nate.com/view/20260731n31916))가 있으므로 프로필에 소속·등록 정보 명시하고 DM 상담 유도는 하지 않음.

### 7-1. 대한변협 「변호사 광고에 관한 규정」(2025-02-06 개정, 2025-02-10 공포; 규칙 2025-06-30 개정)
- 원문: [변협 규정](https://www.koreanbar.or.kr/pages/board/law_view.asp?category=3&page=1&searchstr=&searchtype=&seq=14402&teamcode=&types=6), [규칙 2025-06-30](https://www.koreanbar.or.kr/pages/board/law_view.asp?teamcode=&category=3&page=1&seq=14681&types=6&searchtype=&searchstr=), 해설: [로이어애드 가이드](https://blog.lawyerad.kr/lawyer-advertising-regulations-guide), [아이보스 정리](https://www.i-boss.co.kr/ab-6141-66357).
- 콘텐츠 마케팅에 직접 영향:
  1. **광고 정의 확대** → 블로그·유튜브·스레드 글도 변호사 업무와 연결되면 광고로 취급될 수 있음. 정보성 글에도 실명·소속 표기.
  2. **블로그 광고책임변호사 표시 의무** → 허브 사이트·네이버 블로그 푸터에 고정. 유튜브 영상에 사무소명·전화가 노출되면 광고책임변호사 명시 필요 ([법조신문 질의회신](https://news.koreanbar.or.kr/news/articleView.html?idxno=21098)).
  3. **AI 광고 규제 신설** → "변호사가 AI를 사용한다"고 광고하려면 AI 시스템을 협회에 사전 등록. 이 키트가 "변호사 업무에 AI 사용" 광고로 해석될지, "일반인 대상 교육 디지털 상품"인지 경계가 모호 → **판매 전 변협 질의회신 권장**. 대륜이 이 조항을 공정위에 신고한 상태 ([로팩트](https://www.lawfact.co.kr/news_view.jsp?ncd=4194)).
  4. **무료·염가 표방 광고 금지** → "무료 상담", "할인쿠폰", "9,900원 특가" 류 표현 금지. 리드마그넷은 "자료 제공"으로 표현하고 상담과 연결하지 않음. '무료 상담' 징계 논란 진행 중 ([네이트 2026-03-10](https://m.news.nate.com/view/20260310n26911)).
  5. **결과 보장·과장 금지** → "승소율", "무조건 이깁니다" 금지. YTN 승소 사례 인용은 "보도 인용"으로만.
  6. **타인 명의·대행사 블로그 게시 금지** → 대행사 활용 시 반드시 본인 계정.
