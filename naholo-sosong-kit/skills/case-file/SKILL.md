# 사건 파일 구조

모든 사건 정보는 작업 폴더의 `case/` 아래에 마크다운으로 저장한다. 세션이 바뀌어도 이 파일들만 읽으면 이어갈 수 있다.

```
case/
  00_intake.md      # 인터뷰 결과: 당사자, 사건 개요, 청구 금액, 목표
  10_chronology.md  # 시간순 사실관계 표 (날짜 | 사실 | 근거 증거 | 출처: 사용자 진술/문서)
  20_elements.md    # 요건사실 매칭 표 (요건 | 사실 | 증거 | 상태: 충족/부족/다툼예상)
  30_evidence.md    # 증거표 (갑 제1호증… | 제목 | 입증취지 | 보유 여부 | 원본/사본)
  40_drafts/        # 소장, 답변서, 준비서면 초안 (버전별 파일)
  50_opponent/      # 상대방 서면과 쉬운 말 해설
  60_fees.md        # 인지·송달료 계산 결과
  90_status.md      # 현재 단계, 다음 할 일, 마감일, 미해결 질문
```

## 규칙
- 파일이 없으면 `templates/case/`의 템플릿을 복사해 만든다.
- 사용자 진술과 문서 근거를 구분한다. 진술만 있는 사실은 `(진술)` 표시.
- 수정 시 덮어쓰되, 소장 초안은 `40_drafts/소장_v1.md`, `_v2.md` 식으로 버전을 남긴다.
- 단계가 끝날 때마다 `90_status.md`를 갱신하고, 사용자에게 "새 세션에서 이어가려면 `/naholo:status` 를 실행하세요"라고 안내한다.
- 개인정보(주민번호, 계좌번호 전체)는 파일에 저장하지 않는다. 필요한 경우 마스킹(예: 123456-*******).
